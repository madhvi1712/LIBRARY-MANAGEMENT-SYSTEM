# LIBRARY-MANAGEMENT-SYSTEM
A simple C++ program to manage library records using Object-Oriented Programming (OOP) concepts. It lets you add books, manage members, and track borrowing records efficiently.

### Features
- Add new books (Book Code, Title, Author)
- Register library members (Member Code, Full Name)
- Display all books with real-time status (Available / Issued)
- Search books by Title, Author, or Book Code
- Issue and return books with member verification
- View active borrowing and issuance records
- Delete book records from inventory

### How to Run
```bash
g++ LMS.cpp -o app
./app
